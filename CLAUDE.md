# Project Rules

Этот проект — не обычное портфолио.

Сам сайт является главным проектом портфолио и должен демонстрировать уровень разработки.

## Главные принципы

- Думай как опытный UI/UX дизайнер, а потом как разработчик.
- Не используй шаблонные решения.
- Не создавай типичный AI-дизайн.
- Каждый блок должен иметь собственную идею.
- Каждый элемент должен иметь смысл.
- Всегда выбирай более минималистичное решение.
- Если есть выбор между сложным и элегантным — выбирай элегантное.

## Дизайн

Основные ориентиры:

- Apple
- Linear
- Raycast
- Stripe
- Minimalism
- Liquid Glass

Не копируй их.

Используй только как ориентир по качеству исполнения.

## Код

Перед созданием нового компонента сначала подумай:

- можно ли его переиспользовать;
- можно ли сделать проще;
- не нарушает ли он единый стиль сайта.

Предпочитай качество количеству.

Лучше сделать меньше элементов, но значительно лучше.
